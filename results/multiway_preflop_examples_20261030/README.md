# 特徴的なプリフロップ手札：相手2人・3人への拡張

## 条件

前回取り上げた11手札（AA、22、55、65s、A9o、AKs、AKo、72o、32o、42s、42o）について、相手1・2・3人を比較しました。2・3人はそれぞれ30万配布のモンテカルロ推定、1人は以前のrandom100万・厳格30万配布の結果を再使用しています。

- random：相手全員が残りの合法な手札から一様。
- 厳格：相手全員が `99+,AQs+,AKo` に属する実コンボから一様。
- 厳格モデルでは、各相手を独立に抽選してからカード重複のある全配布を棄却し、合法な組み合わせのもとで全体正規化。順番に相手レンジを狭める方法は使いません。
- 共有ボードを残りカードから一様に配り、全員がショーダウン。全員参加が条件で、ベット・フォールド・レーク・サイドポットは含みません。
- エクイティはポットの期待取り分。自分を含むk人で引き分けた場合は1/kです。単独勝率とは異なります。

## 主な結果：エクイティ

|手札|random相手1人|random相手2人|random相手3人|厳格相手1人|厳格相手2人|厳格相手3人|
|---|---:|---:|---:|---:|---:|---:|
|AA|85.19%|73.34%|63.93%|82.88%|69.65%|59.07%|
|22|50.29%|30.81%|21.87%|30.01%|20.01%|15.98%|
|55|60.36%|40.20%|28.81%|31.49%|21.39%|17.23%|
|65s|43.09%|30.29%|23.74%|28.55%|23.41%|21.40%|
|A9o|60.74%|41.58%|31.07%|25.84%|14.92%|9.84%|
|72o|34.60%|20.55%|14.29%|18.70%|12.99%|10.96%|
|32o|32.38%|19.77%|14.04%|20.88%|15.30%|13.21%|

65sとA9oは、相手が2人・3人でも、randomではA9oが上、厳格では65sが上でした。65sと22をrandom相手で比べると、1・2人では22が上ですが、3人では65sが上でした。この結果は特定のモデルのショーダウン比較であり、プレイ戦略の優劣を直接示すものではありません。

例として65s・厳格相手2人のエクイティ95%正規近似区間は23.254〜23.556%、A9oは14.798〜15.049%。相手3人の同区間は65sが21.248〜21.542%、A9oが9.739〜9.947%です。これらは各推定ごとのサンプリング誤差で、全手札を同時に95%で覆う区間ではありません。

## 検証・限界

既存の相対勝率APIを使って65sの相手2人・3人をrandomと厳格の両方で再サンプリングし、独立推定値と比較しました。差は合成標準誤差の0.04〜0.80倍でした。これは限定条件の確認で、全ハンドや多人数均衡を保証するものではありません。

この実験は選んだ11種類だけです。相手が各自異なるレンジの場合や、相手の反応が行動に応じて変化する場合は別途評価が必要です。
