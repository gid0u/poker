# 参加者5〜8人の追加検証

参加人数は自分を含む人数です。5〜8人（相手4〜7人）を追加し、前回までの2〜4人・9人と結合しました。手札はAA、22、55、65s、A9o、AKs、AKo、72o、32o、42s、42oの11種類。

各新規条件10万配布の推定。相手は全員random、または全員 `99+,AQs+,AKo` の厳格レンジ。既存の2〜4人・9人は、それぞれ以前の標本数・seedの結果です。全員参加・ショーダウンを仮定し、引き分けでは勝者数でポットを等分します。

## 観察

- 65sはrandom相手なら人数とともに低下。厳格相手では5人20.94%、7人20.64%、8人21.97%、9人23.76%。5〜7人間の小さい差はサンプリング誤差を考慮すべきです。
- 65sの5人卓ではrandom 19.32%（個別95%区間19.08〜19.56%）に対し厳格20.94%（20.68〜21.21%）。前回4人卓ではrandom 23.74%・厳格21.39%でした。今回の条件では、相手全員が厳格のほうが高い値になる転換が5人で見られます。
- 厳格相手のAAは8人39.74%、9人41.74%。65sと同様、人数が増えるにつれて必ず減るとは限りません。
- これは「一度配った同じ卓へ、もう1人を後から無条件で追加する」比較ではなく、各人数で独立に『全相手がその狭いレンジ、カード重複なし』を条件とした別々の確率分布です。全員が厳格なとき、既に相手へ配られた高いカードがボードから減る影響があります。これだけでエクイティ変化の全因果を説明したとはいえません。

## 方法・確認

厳格レンジは相手ごとに独立な一様事前分布を置き、全員のカード重複なしを条件にします。合法コンボから順番に抽選した提案分布の偏りを、各段階の合法コンボ率の積による重要度重みで補正。自己正規化重要度推定なので有限標本バイアスがあり、標準誤差と95%区間は加重残差からの漸近正規近似です。新規条件の有効標本数の最小値は54,247（10万提案中）でした。信頼区間は各条件ごとで、全条件同時の95%区間ではありません。

独立した全員分の同時抽選・重複時に配布全体を棄却する方法で、5人random AA、5人厳格65s、8人厳格AA・65sを各5,000サンプル再検証しました。推定差は合成標準誤差の最大2.16倍で、事前に設定した5倍基準内でした。5人random AAは最初の5,000サンプルで2.16倍だったため、別seed・50,000サンプルで追加確認し、差は0.82倍でした。5倍基準は厳密な同値性の証明でも95%被覆率の検証でもありません。

可変人数へ拡張した重要度サンプラーは、相手8人の明示指定と既定値で、同じseedの結果が完全一致しました。関連27テストも通っています。
