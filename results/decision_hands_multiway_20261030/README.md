# 判断に注意したいプリフロップ手札：多人数の追加検証

## 条件

前回のリストで多人数の数値が不足していた33、44、99、TT、JJ、AQs、A5s、KQo、KQs、JTs、T9sを追加しました。既存のAA、22、55、65s、A9o、AKs、AKo、72o、32o、42s、42oと合わせ、22種類・参加2〜9人・2つの相手モデルを比較できます。

- 参加人数は自分を含む。相手は1〜8人。
- random：相手全員が合法な2枚からランダム。
- 厳格：相手全員が `99+,AQs+,AKo` の合法コンボに入ると仮定。
- いずれもカード重複を除き、共通ボードで全員ショーダウン。引き分けは勝者数で分割。
- 新規11手札の3〜9人は、各10万配布提案、計154条件・1,540万提案。2人の結果と既存11手札は以前の計算を再使用しているため標本数は異なります。

相手の参加・ベット・フォールド・ポットサイズ・レーク・サイドポットは含まない、全員参加後のエクイティです。

## 追加で見つかった99とTTの逆転

9人全員参加・相手全員が厳格レンジという条件では、最初の推定は99が7.62%、TTが6.71%。randomでは99が17.22%、TTが19.17%で、順序が逆転しました。

この例は最初の結果を見て選んだため、その後で別seed・別抽選法（全相手を独立に引き、カードが衝突した配布を丸ごと棄却）で各20,000配布を新規に計算しました。

- 99：7.451%、TT：6.911%。差は0.540ポイント。
- 独立した新規抽選での差の近似95%区間は0.047〜1.033ポイント。今回の条件では99が上の方向を支持します。

異なる自分の手札を固定すると、相手が持てる組合せとボードの分布も変わります。この逆転を、どんなボード・レンジでも99がTTより強いと解釈してはいけません。原因をカード除去の寄与などに厳密分解したものでもありません。

## 推定方法と検証

randomは全カードを重複なく一様抽選。厳格は各相手のレンジを独立な一様事前分布とし、全員のカード重複なしという条件で共同正規化します。合法コンボを逐次抽選する提案分布の偏りを、各段階の合法率の積で重要度補正しました。自己正規化推定は有限標本バイアスがあり、95%区間は加重残差による漸近的正規近似です。

新規厳格条件の最小ESSは21,731／10万提案（99・9人）。新規条件の各95%区間の最大半幅はrandom約0.309ポイント、厳格約0.363ポイント。各手札・条件ごとの区間であり、全条件を同時に覆う区間ではありません。

JTs・JJの9人厳格、A5sの6人random、KQoの5人厳格、44の3人randomを、独立した全体棄却法で各6,000配布検証しました。主推定との最大差は合成標準誤差の1.18倍。これは有限例の整合性確認で、全条件の正確性を証明するものではありません。既存の相対勝率・多人数研究の27テストも成功しました。
