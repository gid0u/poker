# ポストフロップへ拡張した仮説検証（2026-10-30）

## 対象と方法

6種類のフロップ（高カード・ドロー・同スート・ペア・連結など）と8種類の実カード手札を組み合わせ、カード重複の2組を除いた46局面を調べました。プリフロップ169種類のようなスート抽象化ではなく、すべて明示された実カードです。

- フロップ：46局面。
- そこから可能なターン：46×47＝2,162局面。
- 最終リバー盤面：46×C(47,2)＝49,726局面。
- 主分析：49,228,740の合法な共有ボード・相手配布を全列挙。
- 相手：残りカードから等確率の1人。追加のレンジ比較だけTT,99。
- 全員ショーダウン参加。ベット・フォールドは含みません。

各フロップは残り47枚からボード2枚を選ぶ1,081通りを列挙し、各最終ボードで相手の45C2＝990通りを評価しました。各最終ボードの相手配布数が同じ990なので、ボード別エクイティを一様平均した値が全体の正しいエクイティになります。限定レンジについてはこれを流用せず、既存APIで重複を条件付けした全列挙を行っています。

主分析の結果はモンテカルロ推定ではなく全列挙値です。浮動小数点による表示丸めはあります。下記の頻度は設計した有限の局面集合内の値であり、自然なポーカー全局面の発生頻度ではありません。

## 仮説1：ターンが開くと、どの分岐でも順位分散が減る

**反例あり。** 2,162ターン分岐中187分岐で、残る順位分散がフロップより増えました。

最大増加の例：

- 自分7c 2h、フロップQs Js 8s。
- フロップ時点の順位分散：約2,863,022.36。
- ターン9sが出ると順位分散：約5,436,357.03。
- 増加：約2,573,334.67。

一方、全46フロップで「全ターンを平均した残存分散」は元の分散以下になりました。条件付き全分散の公式、

Var(R|flop) = E[Var(R|turn)|flop] + Var(E[R|turn]|flop)

の数値誤差は最大9.32e-10。ボード別エクイティqについての同じ公式も最大2.78e-17の誤差で成立しています。

**情報が増えると不確実性は平均では減るが、実現した1分岐で増える場合はある**、という理論を具体的なカードで確認しました。特にボード自身が強い役になる可能性も、自分の順位分散を大きくします。

## 仮説2：リバーで自分の順位分散が0なら、対戦結果もほぼ確定する

**反例あり。** 全49,726リバー局面は自分の最終順位が確定して分散0ですが、49,189局面のエクイティは0と1の間でした。

同じ自分・同じフロップ・同じ最終順位で、最大52.3232ポイントのエクイティ差が見つかりました。

自分7c 2h、フロップTs 9s 2c、相手random：

|最終ボード|自分の順位|自分の順位分散|エクイティ|
|---|---:|---:|---:|
|Ts 9s 2c 7s 8s|3209|0|37.3737%|
|Ts 9s 2c 3c 7h|3209|0|89.6970%|

両方とも自分のベストハンドは同じ順位のツーペアです。相手が作れる役とカード除去条件が異なるため、相対的な強さは大きく異なります。両局面の相手全990コンボを既存APIでも別に列挙し、一致を確認しました。

「自分の役順位が分かること」と「相手に勝てるか分かること」は区別する必要があります。

## 仮説3：順位分散が大きい手札ほど、将来のボード別エクイティも大きくばらつく

**単調な対応への反例あり。** 46フロップ局面の全1,035組中208組で、順位分散とボード別エクイティ分散の大小が逆でした。

同じフロップTs 9s 2cの例：

|自分|順位分散|ボード別エクイティ分散|エクイティ|
|---|---:|---:|---:|
|As Ks|5,496,210.03|0.075664|70.7522%|
|6s 5s|5,142,777.54|0.165900|47.8423%|

As Ksの方が順位分散は大きいのに、6s 5sの方がボード別エクイティの分散は2倍以上です。

ここでq(B)は、最終ボードBを固定して相手990コンボを平均したエクイティです。今回初めて、そのq(B)の分散を全列挙で求めました。単一配布で勝った・負けたという取り分の分散や、モンテカルロ平均の標準誤差ではありません。

またE[q(B)^2]=Var(q(B))+E[q(B)]^2もフロップ・ターンの全行に保存しました。これにより、順位モーメントと、将来の相対強度のモーメントを直接比較する基盤ができました。

## 仮説4：相手レンジが変わっても、自分の候補手札の優劣は変わらない

**同じフロップで逆転を確認。** ボードTs 9s 2c：

|自分|相手random|相手TT,99（セットのレンジ）|
|---|---:|---:|
|As Ah|84.2998%|12.3737%|
|Qs Js|73.5281%|42.1212%|

randomに対してはAAが上ですが、セットのレンジに対してはQs Jsが上です。後者は相手レンジと残りボードの全5,940配布を既存APIで列挙しました。両ヒーローとも相手TT,99のコンボを直接ブロックしていないため、同じ6相手コンボで比較しています。

この比較は「どちらを配られるか」という条件付きエクイティの比較です。実際の一局で自分が手札を交換できるという意味ではなく、ベットEVの比較でもありません。

## 独立した確認

- ターン3局面（最大分散増加例を含む）を既存相対勝率APIで各45,540配布全列挙：エクイティと順位分散が一致。
- リバーの最大差反例を既存APIで各990配布全列挙：順位・エクイティが一致。
- フロップ2局面を既存APIで各2万サンプル確認：全列挙値との差は0.595、1.609標準誤差。
- 全46フロップで、順位平均・エクイティ平均の塔の法則、および2種類の全分散公式を検査。

## 範囲と残課題

46フロップの選択は、多様な特徴を見るための固定パネルです。全ての合法フロップや全実カード手札を列挙した研究ではないため、187/2162などの比率を一般的な発生確率として解釈しません。反例は全称仮説を崩せますが、このパネル内で成立する性質の全局面への一般化は別の検証が必要です。

既存のプリフロップ回帰モデルをそのままポストフロップへ外挿する検証は行っていません。今回は仮説を不確実性の変化・順位と相対強度の違い・相手レンジへの依存へ広げました。

## 保存物と再実行

- config.json：対象カードと仮説。
- flop_states.csv：46行。順位平均・分散、エクイティ、ボード別エクイティ分散・二乗平均、ターンでの分解。
- turn_states.csv：2,162行。同指標とフロップからの分散変化。
- river_states.csv：49,726行。確定順位と相手990コンボへの勝率・引き分け・エクイティ。
- results.json：仮説別の件数・反例・検算。
- postflop_summary.png / svg / pdf：結果図。

numpyと既存の全7枚辞書が必要です。描画だけmatplotlibが必要です。本体コードは変更していません。

```powershell
$env:PYTHONPATH="$PWD\src"
.venv-studio/Scripts/python.exe experiments/postflop_hypotheses.py --dictionary data/processed/seven_card_dictionary --output results/postflop_hypotheses_20261030
.venv-studio/Scripts/python.exe experiments/plot_postflop_hypotheses.py
```

API照合の丸め差：最大分散増加例では、順位分散約543万に対する実装間の絶対差は約2.32e-6（相対差約4.3e-13）でした。小さな配布確率を多数回加算する丸め差として、分散の照合には相対許容誤差1e-11と絶対許容誤差1e-6を使用し、各差をresults.jsonに保存しています。エクイティ差は約3.4e-14でした。
