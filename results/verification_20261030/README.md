## 研究データの確認

全169種類の正確な順位平均・分散を実コンボ数で重み付けすると、全7枚辞書の集計を復元できました。

- 平均順位：4095.8835905428846
- 全分散の公式で復元した分散：3144968.317189278
- 保存済みのエクイティを実コンボ数で重み付け：50.002985%。理論上の50%との差は0.725標準誤差。

新しいseedで通常の相対勝率APIを各10万配布実行し、既存のベクトル化実験の保存結果と比較しました。

|手札|保存済み100万配布のエクイティ|新しい10万配布|差 / 合成標準誤差|
|---|---:|---:|---:|
|AA|85.19335%|85.34750%|1.321|
|55|60.36010%|59.93100%|2.660|
|72o|34.60085%|34.28200%|2.093|

これらは事前に設定した5合成標準誤差の検査基準を通過しました。ただし、全てが95%の目安内にあるわけではありません。独立再計算で毎回同じ小数値になる保証や、95%区間の被覆率の証明とは解釈できません。55がrandom1人に対して有利という結論は両方の計算で維持されています。
