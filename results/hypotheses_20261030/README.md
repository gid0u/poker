# 検証可能な3仮説と検証結果（2026-10-30）

## 結論

1. **分散を加えるとエクイティ予測が改善するか**：二次モデルでは改善。線形モデルではほとんど改善せず、個別手札の大きな誤差も残りました。
2. **同スートによるエクイティ上昇は一定か**：一定とはいえません。手札によって推定約1.60〜3.63ポイントの差があります。
3. **平均順位が強い手札ほどエクイティも高いか**：反例あり。65sとA9oで大きく逆転し、新しいseedの各50万配布でも確認できました。

この分析は既存データを使った探索的研究です。データ自体は過去の分析で見ているため、完全な事前登録試験ではありません。今回の計算開始時に仮説・モデル・評価方法をconfig.jsonへ記録し、逆転の確認対象も新しい抽選結果を見る前にconfirmation_selection.jsonへ固定しています。

## 条件

自分は169種類の代表実カード2枚、相手は合法な全2枚から等確率の1人、ボードは未定、全員ショーダウン参加です。

- 入力特徴：各手札の正確な最終順位平均・順位分散。
- 教師値：既存の各100万配布から推定したエクイティ（勝ち1、引き分け1/2、負け0）。
- 検証分割：91種類のランク組を1組ずつ除外。同じランクの同スート・異スートは両方とも同時に学習から外します。
- 平均・標準偏差による特徴の標準化も、各分割の学習データだけで計算しています。
- 169種類を等重みで評価する場合と、実コンボ数（ペア6・同スート4・異スート12）で重み付けする場合を両方計算しました。

## 仮説1：分散の追加で予測誤差が10%以上減る

主比較は平均順位だけの二次モデル（3係数）と、平均順位・分散の二次モデル（6係数）。後者は平均×分散の交互作用も含みます。モデル式はrank meanをmu、rank varianceをvとすると、1, mu, v, mu^2, mu*v, v^2です。

|モデル|種類を等重み：RMSE|実コンボ数で加重：RMSE|
|---|---:|---:|
|平均のみ・線形|5.418ポイント|5.567ポイント|
|平均＋分散・線形|5.418ポイント|5.545ポイント|
|平均のみ・二次|4.983ポイント|4.989ポイント|
|平均＋分散・二次|**4.120ポイント**|**3.801ポイント**|
|平均のみ・五次（6係数）|4.796ポイント|4.764ポイント|

主比較のRMSE改善率は17.32%と23.81%で、設定した10%基準を通過しました。同じ6係数の平均のみ五次モデルよりも、平均＋分散モデルの誤差が小さくなっています。

ただし線形ではほぼ改善しません。分散を足せば任意のモデルで改善するという結論ではありません。また主比較では最大絶対誤差が11.47→17.52ポイントへ悪化しました（種類を等重み）。平均的な改善と個々の最大誤差は別です。

特にAAは予測67.67%に対して推定値85.19%、22は予測64.45%に対して推定値50.29%。AAのように特徴空間の端を除外した場合は外挿となることも、この評価の難しさです。順位平均・分散の2特徴だけで十分に精密な評価器になったとはいえません。

数値の最小値だけを選んで最適モデルが確定したとする分析ではなく、あらかじめ挙げた小さなモデル集合での比較です。別のモデル・相手レンジ・ストリートへの一般化は未検証です。

## 仮説2：同スートの上昇幅は一定

全78ランク組の同スートと異スートのエクイティ差を計算しました。両推定のseedストリームは別で、差の標準誤差は二乗和の平方根としています。

- 一定上昇幅を仮定した逆分散加重推定：約2.747ポイント。
- 異質性統計Q=4669.92、自由度77。独立正規近似で一定幅ならQの期待値は77なので、計測誤差だけで一定幅からのずれを説明する仮説とは大きく不整合です。
- AKs−AKo：約**1.602ポイント**。
- 42s−42o：約**3.634ポイント**。

全78組についてBonferroni補正した正規近似95%区間も計算しました（z=3.414）。すべての下限が0を上回りました。したがって、このランダム相手・ボード未定条件では、全78組で同スートが有利であることがサンプリング誤差を考慮しても支持されます。

上の最小・最大は推定値から選んだ組であり、近い組の厳密な順位は確定していません。この性質を既知ボードや任意の相手レンジへ一般化してはいません。

## 仮説3：平均順位の順序がエクイティの順序と一致する

169手札の全14,196組を比較すると、推定値では2,338組で順序が逆転しました。全組の比較に対するBonferroni補正の正規近似95%差区間でも、2,235組は逆転方向の下限が0を上回りました。

探索で最大のエクイティ差となった逆転を選び、新しいseedで確認しました。

|手札|正確な平均順位（小さいほど強い）|既存100万配布のエクイティ|新規50万配布のエクイティ|
|---|---:|---:|---:|
|65s（6s 5s）|4020.519|43.0876%|**43.1892%**|
|A9o（As 9c）|4028.276|60.7399%|**60.7591%**|

平均順位は65sが約7.757だけ強いにもかかわらず、エクイティはA9oが新規確認で**17.5699ポイント高い**結果でした。差の正規近似95%区間は**17.3813〜17.7585ポイント**です。

これは前の既知ボードの反例に加え、プリフロップ169種類の同じrandom相手条件でも、平均順位だけを相対強度の順序として使えないことを示しています。エクイティ自体は推定なので、論理的に全列挙した厳密反例とは区別しています。

## 分析コード自体の検証

verify_hypothesis_analysis.pyで以下を確認しました。

- 分割が91ランク組である。
- 除外したAK組の正解エクイティを大きく変更しても、AK組自身への予測が変わらない（正解の漏れを検査）。
