# ポストフロップ未知局面の予測検証（2026-10-30）

## 結果

指定された順に、層別抽出、正解データ作成、未知ボード群の分離、5種類の特徴の比較、局面別・最大誤差の分析を行いました。

1. 未知フロップ群では、平均順位のみより、ボードと手札の特徴を加えたモデルの誤差が大きく低下。
2. 独立に計算した別の相手レンジのエクイティを加えると、特に厳格レンジ相手の予測が改善。
3. その別レンジの分散・分位点も追加した効果は小さく、今回の検証では明確とはいえない。
4. より厳しい「同スート3枚のフロップを全て学習から外す」検証では、モデルの誤差が大きくなった。局面の分布が変わると汎用化が難しい。
5. 平均誤差が約4.5〜4.7ポイントでも、個別の誤差は15〜21ポイントに達する。実戦の精密予測には不十分。

## 1. 対象局面

52枚のC(52,3)=22,100フロップを列挙し、スートの置換で同一になるものをまとめると1,755グループです。それらを互いに重ならない5層へ分類しました。

|層|全グループ数|抽出グループ数|手札数/グループ|
|---|---:|---:|---:|
|ペア・スリーカードを含む|325|120|4|
|同スート3枚|286|120|4|
|2スート、ランクの最大差4以下|174|120|4|
|2スート、その他|684|120|4|
|3スート|286|120|4|

合計600フロップ群×4手札＝2,400実カード局面。手札はボードと重複しないC(49,2)から、各グループについて無作為に4組を重複なく抽出しました。接続度は単純なランク最大差による層分けで、Aを低く使うホイールを特別扱いする分類ではありません。

各層の等重み評価と、各フロップ群が代表する実カードの組合せ数・各層の全グループ数を反映した加重評価を保存しました。後者は、まず手札とボードが一様に配られた局面を評価する目的の重みで、厳格な相手が参加した後の実際の局面出現頻度やプレイヤーの意思決定頻度を推定するものではありません。

## 2. エクイティの正解データ

- 相手1：random。相手2：`99+,AQs+,AKo` の合法コンボから等確率。
- 各局面・各相手について独立のseedで10,000配布、合計4,800万配布のMC推定。手札・ボードの重複を禁止し、同じボードで比較。標準誤差も保存。
- 順位平均・分散は、自分の既知カードを除いたC(47,2)=1,081の最終ボードから正確に求めました。これは相手カードを条件付けない特徴量であり、厳格レンジを条件とした順位分布とは異なります。
- 別レンジ特徴の`QQ+,AK`は、目標のrandom・厳格とは独立のseedで、相手を選んでから合法ボードを64個抽選し、各ボードで合法な相手コンボを全列挙。64個のボード別エクイティの平均、経験分散、経験10%・50%・90%分位点を特徴としました。64個による分布特徴自体にも標本誤差があり、追加計算コストを要します。

エクイティは引き分けを半分とする取り分です。ベット、フォールド、レーク、相手の観測行動は含みません。

## 3. 未知局面の分離

主検証では各層の120フロップ群から30群を評価へ隔離し、計450群・1,800局面で学習、150群・600局面で評価しました。同じフロップ群に属する異なる手札や、スートの置換で同じになるフロップは学習側と評価側にまたがりません。各モデルの特徴標準化は学習側のみに基づきます。

追加検証では、同スート3枚の120群・480局面をすべて学習から除外し、それ以外の480群・1,920局面で学習しました。これは新しい種類のボードへの外挿を試す検証です。2種類の検証は評価対象群と学習量が異なるため、そのまま厳密な同一対象の前後比較にはなりません。

## 4. 予測モデル

すべて同じリッジ回帰（係数正則化2、学習側で標準化、予測値0〜1に切り詰め）で、順に入力を追加しました。

1. 最終順位の平均とその二乗。
2. 上記＋順位分散、その二乗、平均×分散。
3. 上記＋ボード最高・最低ランク、ランク幅、最大同スート枚数、ランク種類数、手札とフロップで作る5枚役のカテゴリ、自分の高低ランク・同スート。
4. 上記＋独立計算したQQ+,AK相手のボード別エクイティ平均。
5. 上記＋その経験分散・10%・50%・90%分位点。

別レンジ特徴は検証側の局面に対しても別途計算する入力で、評価対象の勝敗サンプルとは独立ですが、追加の役判定を必要とします。同一計算コスト下の比較ではなく、性能改善を無料で得たことにはなりません。

## 5. 未知フロップ群の評価

実カードの組合せ数で加重したRMSE（エクイティのパーセントポイント）：

|入力|random相手|厳格レンジ相手|
|---|---:|---:|
|順位平均|11.884|13.248|
|＋順位分散|11.768|12.966|
|＋ボード・手札特徴|4.859|7.709|
|＋別レンジの平均|4.723|4.598|
|＋別レンジの分布|4.669|4.504|

この有限サンプルとモデルでは、順位分散のみの追加効果は小さく、ボード・手札の情報が大きく役立ちました。厳格レンジへの予測では、別レンジ平均も有効でした。ただしその特徴は相手レンジ`QQ+,AK`に対する別途計算したエクイティであり、新しい情報と計算が追加されています。

推定ラベルの標準誤差の加重二乗平均平方根は約0.4〜0.5ポイントです。表のRMSEは予測誤差とラベルのMC誤差を含みます。

検証側のフロップ群を層別・群単位で1,000回再標本化し、固定済みモデル同士のRMSE差を比較しました（再学習せず、計算済みラベルを固定した条件付き区間）。別レンジの平均からさらに分布を加えた差の95%区間は、randomで−0.059〜0.172ポイント、厳格で−0.0003〜0.196ポイント。いずれも0を含むため、今回のサンプルでは分布追加の効果を確実とは判断しません。この区間は学習データ・モデル選択・MCラベルの全不確実性を含むものではありません。

### 局面ごとの誤差

平均＋分散＋ボード・手札＋別レンジ分布モデルについて、random相手の未知群でのRMSEは、ペアボード7.19、同スート3枚6.17、3スート3.82ポイントでした。各層は120局面、30ボード群です。これはこのモデルと抽出データの結果で、全局面への保証ではありません。

5枚役がスリーカードの局面ではrandom相手RMSE11.55ポイントですが、評価側18局面に限られるため精度のよい母集団推定ではありません。

最大誤差の探索後、それぞれ1局面を選んで全列挙で再確認しました。

|相手|手札|フロップ|モデル予測|MC推定|全列挙|
|---|---|---|---:|---:|---:|
|random|4c 5d|5s 5c Th|72.62%|93.99%|93.55%|
|厳格|8c Kc|2s 6c Kh|49.77%|65.31%|65.36%|

MC推定と全列挙の差はそれぞれ1.94、0.11標準誤差。二つの全列挙値は、別の既存APIでも照合しました。これらは最大誤差として選んだ例であり、典型例ではありません。

### 同スート3枚を未学習にした検証

同じ加重RMSEは、最終モデルでrandom相手8.142ポイント、厳格相手6.571ポイントでした。分布特徴が他の特徴より必ず優れるとは限らず、厳格相手では分布を加える前のモデル5.862ポイントより悪化しました。未学習のボード種への外挿では、特にモデル構造・特徴表現の検討が必要です。

## 検証と残課題

- 2,400局面すべてについて24通りのスート置換後の正規化を確認（57,600回）。学習・評価のフロップ群に重複なし。
- 評価側の正解ラベルを書き換えても評価側の予測が変わらないことを検査。
- 最大誤差2例は独立の既存APIの全列挙で再確認。
- 特徴・seed・分割・重み・各予測値と結果を保存。

今回評価したのは、すでに指定された2種類の相手レンジで学習し、未知フロップを予測する能力です。未知の相手レンジへの汎化、ターン・リバーでのモデル性能、複数人、戦略やEVの改善を証明したものではありません。また、正解に近い独立再計算を特徴へ入れた場合、別途の計算量と、サンプルを変えた頑健性を評価する必要があります。

## 再現

numpy、既存7枚辞書が必要です。描画はmatplotlibを使用します。

```powershell
$env:PYTHONPATH="$PWD\src"
.venv-studio/Scripts/python.exe experiments/postflop_generalization.py --dictionary data/processed/seven_card_dictionary --output results/postflop_generalization_20261030
.venv-studio/Scripts/python.exe experiments/verify_postflop_generalization.py --dictionary data/processed/seven_card_dictionary
.venv-studio/Scripts/python.exe experiments/plot_postflop_generalization.py
```

- `states.csv`：局面・特徴・教師値・seedで再現する条件・重み・分割。
- `predictions.csv`：各分割・各モデルの全予測と誤差。
- `metrics.csv`、`subgroup_metrics.csv`：全体・層別・役別の誤差。
- `bootstrap_differences.csv`：固定モデルに対する群単位ブートストラップ。
- `exact_selection.json`、`results.json`、`verification.json`：選択例・全列挙・検算。
- `generalization_summary.png/svg/pdf`：図。
