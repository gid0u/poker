# ランダム参加と厳格な参加レンジの比較・既存研究との対応（2026-10-30）

## 相手の定義

「厳格に強いハンドだけ参加」は、この実験ではプリフロップで以下の固定レンジだけ参加することと定義しました。いったん参加した後はショーダウンまで進むモデルです。

|相手|参加レンジ|カード除去前の実コンボ数|全1326コンボに対する割合|
|---|---|---:|---:|
|random|全手札|1326|100%|
|tight（主比較）|99+,AQs+,AKo|56|約4.22%|
|ultra_tight（感度分析）|QQ+,AK|34|約2.56%|

56コンボの内訳は99/TT/JJ/QQ/KK/AA＝36、AQs/AKs＝8、AKo＝12です。34コンボはQQ/KK/AA＝18、AKs/AKo＝16です。特定の指標による厳密な「上位4.22%」と定義したものではなく、明示的に選んだ狭いレンジです。範囲内の各実コンボは等確率で、既知カードとの重複は除外します。

**相手がすでに参加したことを条件としたエクイティ**を比較します。参加しなかったハンドのfold、ブラインドの利益、ベット・レーク・参加後の追加選別は評価に入れません。これは前回の特定ボードでのセットレンジTT,99とも異なります。

## 計算範囲

- プリフロップ169種類×狭い2レンジ×各30万配布＝新規1億140万配布。randomは既存の各100万配布を再使用。
- 同じ46フロップ・2162ターン・49726リバーを、狭い2レンジで全列挙。追加CSVはそれぞれ92行・4324行・99452行。
- 既存の正確な自分の役順位は再利用し、相手レンジへの勝敗を再計算。
- プリフロップの数値は推定で95%正規近似区間を保存。ポストフロップの主比較は全列挙です。

## 1. プリフロップの比較

以下は引き分けの取り分を含むエクイティです。

|手札|random|tight|ultra_tight|
|---|---:|---:|---:|
|AA|85.19%|82.88%|84.10%|
|KK|82.38%|68.02%|57.15%|
|QQ|79.99%|56.60%|40.30%|
|AKs|66.95%|45.89%|41.97%|
|AKo|65.35%|43.24%|38.80%|
|55|60.36%|31.49%|35.68%|
|22|50.29%|30.01%|33.93%|
|65s|43.09%|28.55%|31.08%|
|72o|34.60%|18.70%|21.37%|

55のtightに対する95%区間は31.326〜31.658%です。「55が平均的に有利」という従来の結論には、相手がrandomであるという条件が必要です。

推定エクイティが50%を上回ったのは、tightではAA/KK/QQ、ultra_tightではAA/KKでした。ただし50%はポットオッズを含む参加・コールの損益分岐点ではありません。

ultra_tightの方が狭くても、55・22・65s等はtightよりエクイティが上がります。レンジを絞ると、自分を苦しめるオーバーペアと、比較的戦いやすい未ペアAKの構成比が変わるためです。「レンジが狭いほど、全ての自分の手札に対して必ず強い」という単調性はありません。

randomの推定序列と比較した全14196組の順序の逆転は、tightで2606組、ultra_tightで5732組でした。これは探索的な推定値の件数であり、全組の統計的有意差を示す数字ではありません。

## 2. ポストフロップでは、強い参加レンジに対して有利になることもある

46フロップ中、tight・ultra_tightとも7局面ではrandomよりエクイティが高くなりました。設計した局面集合内の件数であり、全フロップにおける一般的な頻度ではありません。

自分As Ah、フロップ7s 6h 5d：

|相手|エクイティ（全列挙）|
|---|---:|
|random|72.2160%|
|tight|87.7753%|
|ultra_tight|90.1948%|

プリフロップに強いレンジには、このボードで強くなる低い2ペア・低いセット・一部ストレートなどが含まれない一方、randomには含まれます。したがって「プリフロップに強いレンジ」と「現在のボードで強いレンジ」は区別する必要があります。

同じフロップTs 9s 2cの比較：

|自分|random|tight|ultra_tight|前回のTT,99セットレンジ|
|---|---:|---:|---:|---:|
|As Ah|84.2998%|77.0375%|90.9115%|12.3737%|
|Qs Js|73.5281%|56.6808%|58.3871%|42.1212%|

前回の「セットに対してはQs JsがAAより上」という逆転は、tight/ultra_tightの固定参加レンジへそのまま一般化できません。ultra_tightではTT・99を除くため、このフロップにセットで当たる相手を含まないことも重要です。

## 3. 平均順位・分散の予測モデルは相手ごとに比較する

前回と同じ91分割のランク組除外検証（同じランクのs/oはまとめて除外）、同じモデル、同じrandom時の正確な順位平均・分散を入力特徴に使い、各相手のエクイティを別々に学習・予測しました。したがって下表は、相手を変えた時の同一特徴の予測性能比較です。

|相手|平均のみ二次モデルRMSE（種類等重み）|平均＋分散二次モデルRMSE|改善率|
|---|---:|---:|---:|
|random|4.983ポイント|4.120ポイント|17.32%|
|tight|3.776ポイント|3.484ポイント|約7.74%|
|ultra_tight|4.256ポイント|3.694ポイント|約13.22%|

実コンボ数で重み付けした場合の改善は、random約23.81%、tight約8.91%、ultra_tight約10.92%でした。

分散追加の効果の大きさも相手分布に依存します。前回の「10%以上改善する」という基準は、主tight条件では成立しませんでした。なお相手ごとに教師値の散らばりも異なるため、単純にRMSEの絶対値だけでどの条件が本質的に予測しやすいと断定していません。

また、相手レンジを条件付けると、自分が完成しうるハンドの順位平均・分散自体もカード除去で変わります。CSVにはその条件付きモーメントも記録しています。ただしプリフロップの条件付きモーメントはモンテカルロ推定であり、下表の回帰特徴はそれと混同せず従来のrandom時の正確な値を使用しました。

## 4. ボード確率の重みを無視すると偏る

狭いレンジを置いた場合、各未来ボードと両立できる相手コンボ数m(B)が変わります。一様なレンジ内実コンボを仮定すると、既知フロップ・自分の手札を条件に、未来ボードの確率はm(B)に比例します。

P(B | hero, flop, opponent in range) = m(B) / (m0 * C(45,2))

m0は既知フロップまでと両立する相手コンボ数です。したがって各未来ボードの条件付きエクイティq(B)を単純等平均せず、m(B)で加重しています。

独立検査では全92親フロップについて、ターンの条件付き確率の和、平均順位・エクイティの塔の法則、2種類の全分散公式が一致しました。エクイティの最大誤差は5.56e-16。

具体的には、自分Qc Qh、フロップ9c 9h 2d、相手ultra_tightでは、正しいエクイティ46.7537%に対し、ターン後のエクイティを誤って等平均すると45.1543%になり、約1.60ポイント偏ります。

既存APIとも、4フロップの全列挙および4条件のプリフロップ再抽選を照合し、記録した許容誤差内で一致しました。最大プリフロップ差は1.914合成標準誤差でした。

## 5. 既存研究との比較

### Johansonほか（2013）：Opponent Cluster Hand Strength（OCHS）

[Evaluating State-Space Abstractions in Extensive-Form Games](https://johanson.ca/publications/poker/2013-aamas-kmeans-abstraction/2013-aamas-kmeans-abstraction.pdf) は、複数の相手ハンド集合に対する強度を特徴ベクトルにします。論文では8クラスタを用いています。

今回の(random, tight, ultra_tight)という3条件のエクイティ表は、この「相手分布ごとの強さを複数持つ」考え方と対応します。opponent_strength_features.csvに169手札の3次元特徴を保存しました。ただし今回の3分布は重なりのある手動指定で、論文の学習した8クラスタやクラスタリング・CFR-BRの実験を再現したものではありません。

### Gilpin・Sandholm・Sørensen（2007）：Potential-aware abstraction

[Potential-aware Automated Abstraction…](https://cdn.aaai.org/AAAI/2007/AAAI07-008.pdf) は、強度の平均・分散では失われる分布形状と情報公開経路を論じ、ヒストグラムを使います。

今回の順位平均・分散は役順位のモーメントであり、論文の相対強度と同一尺度ではありません。一方、今回ポストフロップで計算したq(B)の分散は将来の相対強度のモーメントに近い量です。複数相手分布を置いても、平均・分散だけで戦略が十分表現できるとは検証していません。

### Southeyほか（2005）：Bayes’ Bluff

[Bayes’ Bluff: Opponent Modelling in Poker](https://poker.cs.ualberta.ca/publications/UAI05.pdf) は、観測から相手戦略の事後分布を推定し、その分布への応答を扱います。

今回のレンジは行動履歴から学習したものではなく仮定です。「プリフロップ参加した」という選別だけを固定範囲で表しています。実際のベット・チェック・フォールドを観測してレンジを更新することは、今後の拡張になります。

**論文の対戦成績・exploitabilityに対し、今回のRMSEやエクイティを直接優劣比較することはできません。** ここで比較したのは指標の意味と設計の対応です。
