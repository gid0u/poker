## 9人の厳格相手が特殊な理由

「8人全員が厳格レンジで参加した」という条件は、プリフロップから強いカードが多数使われている条件です。例えば自分が6s 5sの場合、相手8人の16枚はいずれも9以上のカード（全24枚）なので、ボードへ残る34枚に9以上は8枚です。将来5枚のボードに含まれる9以上の枚数の期待値は厳密に5×8/34＝約1.18枚となります。

random相手なら、相手のカードを周辺化したボードは手札以外50枚から一様なので、同じ期待値は5×24/50＝2.4枚。相手が3人で全員厳格な場合は5×18/44＝約2.05枚です。つまり8人全員が参加しているという条件はボード分布も大きく変えます。これは今回の意外な数値を理解する上で重要な事実ですが、エクイティ差の全てをこの単一指標だけで因果的に説明したことにはなりません。

参加人数を変更すると、「全員がそのレンジに入り、かつ重複がない」条件自体も変わるため、各人数は異なる条件付き分布です。この研究では、65sの厳格相手への推定エクイティは、相手3人で21.40%、相手8人で23.76%でした。一般に相手を追加するだけで常に増えるという意味ではありません。

## 方法と検証

randomは既知手札を除く50枚から21枚を重複なく一様抽選（相手16枚＋ボード5枚）。

厳格レンジは、各相手について現在重複しない合法コンボから逐次一様に選び、各段階で「元の相手レンジのうち合法な重みの割合」を掛けた重要度重みで補正します。これにより対象は、独立な元レンジの積を全員のカード重複なしで条件付けた分布です。**単純な逐次再正規化の結果をそのまま使ってはいません。** 正規化した重要度推定には有限標本バイアスがあり、区間は漸近的な正規近似です。

厳格条件の有効サンプルサイズは各30万提案に対し約10.4万〜12.3万。小さすぎるESSは見られませんでしたが、他のレンジでは保証されません。区間は個々の手札に対するもので、全手札を同時に95%で覆う区間ではありません。

別の方法として、相手8人をそれぞれ元レンジから独立に引き、重複があれば配布全体を棄却するサンプリングをAA・65sに各4,000回行いました。重要度法との差は合成標準誤差の1.38倍・0.68倍でした。randomの65sも既存APIの独立2万配布との比較で1.47倍でした。既存の相対勝率テスト11件も成功しています。これは限られたケースの整合性確認です。

全員の参加を条件とした配布であり、実際の参加頻度、ブラインド、フォールド、ベット、レーク、サイドポットや多人数均衡の評価ではありません。選んだ11種類の比較であり、169種類全体を計算した結果でもありません。
