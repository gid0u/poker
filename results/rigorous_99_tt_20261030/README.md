# 99 と TT：9人ショーダウンの検証

## 前提

自分は 9s9c または TsTc、相手は8人。各相手の初期レンジは `99+,AQs+,AKo` の物理コンボを等重みとし、自分と相手全員のカードが重複しない条件で同時に条件付ける。残り34枚から共通ボード5枚を一様に配る。全員がショーダウンし、同点は均等分配。数値はポット取り分の期待値（エクイティ）であり、単独勝率やベットのEVではない。範囲・参加人数・重み・戦略を変更すれば結論も変わる。

## 結果

| 指標 | 99 | TT |
| --- | ---: | ---: |
| 対応づけた200万提案のエクイティ | 7.5486% | 6.9223% |
| 独立棄却法、各5万採択 | 7.6529% | 7.2229% |

対応推定の差は +0.6263 ポイント、正規近似95%信頼区間は +0.5960〜+0.6566 ポイント。有効サンプルサイズは約43.9万。自己正規化重点サンプリングで、有限標本バイアスと標本誤差が残る。独立棄却法の差は +0.4300 ポイント、95%区間 +0.1130〜+0.7470 ポイントであり、両推定差は合成標準誤差の1.21倍。

99側の合法配布は席順を区別しなければ 563,904 通り、区別すると 22,736,609,280 通り。これらとボードの組は席順を除いても約1,569億通りあり、勝率の全列挙は実施していない。区間は推定誤差についてのもので、結論を数学的な厳密証明と呼ぶことはできない。

## 厳密に数えたブロッカー効果

レンジにある合法2枚を辺とするグラフのマッチング多項式で、合法相手配布を整数演算で数えた。自分が99の場合、相手にTTが1人以上いる確率は厳密に 954/979 = 97.4464%、相手が99を持つ確率は 5139/7832 = 65.6154%。相手8人のTT人数の期待値は 5505/3916 = 1.40577人。相手8人の99人数の期待値は 5139/7832 = 0.65615人。TTを持つ場合は9とTを入れ替えた関係になる。

全相手カードが9以上なので、相手と自分への配布後、残り34枚のうち9以上は常に6枚。9以上のボード枚数の分布は両手で等しく、期待枚数は 5×6/34 = 0.88235 枚。この結果は、一般的なランダム相手には当てはまらない。99の場合、ボードの9枚数の期待値は約0.10113、T枚数は約0.17477である。

## 対応づけと分解の解釈

カードのスートを保ったまま9とTを全て入れ替えると、相手レンジは自身に写り、99側の合法配布とTT側の合法配布は確率を保った一対一対応になる。ただしポーカーの強さはこの変換で不変ではない。各配布のショーダウン取り分の差を計算し、重み付き平均する。

99側のボードに9とTのどちらもない配布は推定75.19%、全体差への寄与は +1.2095 ポイント。両方ある配布は推定0.93%、寄与は −0.5722 ポイント。9のみ、Tのみの寄与はそれぞれ +0.0002、−0.0112 ポイント。合計が +0.6263 ポイントとなる。グループ内の配布内容は対応変換後も連動して変化するため、これは記述的な分解であり、ボードやブロッカー単独の因果効果ではない。ストレート、ペアの順位、同点分配等の個別の寄与も分離していない。

## 再現・検証

`PYTHONPATH=src` の環境で次を実行する。辞書は既存の seven_card_ranks.u16 を指定する。

```
python experiments/exact_99_tt_matchings.py
python experiments/paired_99_tt.py --dictionary PATH_TO_DICTIONARY --output results/rigorous_99_tt_20261030 --samples 2000000
python experiments/verify_rigorous_99_tt.py --dictionary PATH_TO_DICTIONARY
```

マッチング数は少人数の直接列挙と照合し、9/T変換の対称性を確認した。乱数種・不確実性・追加の内訳は同フォルダの JSON と CSV を参照。通常の戦略を決めるには、実際の参加レンジ、ポジション、ベット・フォールド、人数変化を含む追加検証が必要。
