# 現在のシステムから導ける関係（2026-10-30）

## 前提と証拠の区別

標準52枚、ジョーカーなし、既知カードと重複しない配布を用います。Rは最終7枚から得る役順位（1が最強）です。169手札の平均・母分散は既存の全ボード列挙値、エクイティは明示しない限り既存モンテカルロ推定です。以下では確率の恒等式、有限データの正確な性質、推定結果を区別します。

## 1. 平均順位・分散だけでは、相手がrandomでもエクイティは決まらない

自分をAs Ah、相手を残りカードから等確率の1人に固定し、リバーで全990相手コンボを列挙しました。

|ボード|平均順位|順位分散|エクイティ（全列挙）|
|---|---:|---:|---:|
|Ks 8h 7d 3c 2s|3360|0|89.343434…%|
|Kc 8c 7c 3h 2s|3360|0|84.898989…%|

両者の自分の最終順位は同じであり、平均・分散だけでなく自分の順位の周辺分布全体が同じ点質量です。それでも相対エクイティは約4.4444ポイント違います。

したがって、すべての局面でエクイティを正確に返す普遍的な関数 f(E[R], Var(R)) は存在しません。自分の順位分布全体だけから返す関数についても同じ反例が成立します。ボード・カード除去と相手との同時分布の情報が必要です。これは平均・分散による近似予測の有用性を否定する主張ではありません。

## 2. 全順位分散を手札間と手札内へ正確に分解できる

Hをプリフロップ手札種類、w_hをその実コンボ数/1326、mu_h=E[R|H=h]、v_h=Var(R|H=h)とします。ペアの重みは6/1326、同スート4/1326、異スート12/1326です。169種類を等確率にはしません。

全期待値の公式：

E[R] = sum_h w_h mu_h

全分散の公式：

Var(R) = sum_h w_h v_h + sum_h w_h (mu_h-E[R])^2

既存CSVの整数順位和・二乗和から有理数で計算し、全52C7辞書の有理数集計と完全一致しました。

|成分|順位分散|割合|
|---|---:|---:|
|同じ手札内の将来ボードによる平均分散 E[Var(R|H)]|3,047,883.962370|96.9130%|
|手札ごとの平均順位の違い Var(E[R|H])|97,084.354819|3.0870%|
|全体 Var(R)|3,144,968.317189|100%|

これは、今回の順位尺度で「手札を知ることによって減る最終順位の平均二乗予測誤差」が全体の約3.09%であることも意味します。最良の二乗誤差予測はE[R|H]だからです。

ただし、この割合はポーカーの実力・収益・戦略的重要性の寄与率ではありません。相手との勝敗やベットは含まず、順位番号の尺度に依存します。

なぜ全7枚の分布と一致するか：一様な手札2枚と残りボード5枚から得る任意の7枚集合には、手札を選ぶC(7,2)=21個の分割があるため、最終7枚集合は一様です。スート対称性で169種類にまとめても実コンボ数で重み付けすれば同じ分布です。

## 3. 情報が増えると、不確実性は平均として減る

F_tを時点tまでに分かっている情報とし、同じ合法配布の確率モデルを一貫して更新するとします。

mu_t=E[R|F_t]、v_t=Var(R|F_t)

塔の法則と条件付き全分散から、

E[mu_(t+1)|F_t] = mu_t

v_t = E[v_(t+1)|F_t] + Var(mu_(t+1)|F_t)

よって E[v_(t+1)|F_t] <= v_t です。将来のカードを見た後の平均的な残存不確実性は増えません。その減少量は、次のカードで予想順位がどれだけ動くかの分散に等しくなります。

一方、実際に特定のフロップが出た1経路では分散が増えることもあり、各局面で単調減少するという意味ではありません。また、未公開カードをめくるだけで予想順位が平均的に改善するわけでもありません。

この式から、各手札を「フロップで不確実性がどれだけ解消されるか」「ターン・リバーまでどれだけ残るか」で分解する研究が定義できます。式そのものは導出済みですが、その各ストリート数値は今回未計算です。

## 4. 同スートの左上移動は全78組で確認できるが、順位差とエクイティ差は同じではない

169手札の正確なモーメントから、同じランクのs/o全78組で、

E[R|suited] < E[R|offsuit]

Var(R|suited) > Var(R|offsuit)

を確認しました。この条件・順位尺度での有限全組の性質であり、任意の相手レンジ・既知ボードへの一般定理ではありません。

- 平均順位の改善は約165.065〜201.650。最小は87、最大はAK。
- 既存MCデータのエクイティ増加の推定値は約1.602〜3.634ポイント。
- AKは平均順位の改善が最大なのに、推定エクイティ増加は78組中最小。

従って、少なくとも現在のデータでは「平均順位の改善量をそのまま勝率の改善量として読む」ことはできません。エクイティの最小・最大の順序は推定に依存し、近い組の順序は追加サンプルで入れ替わり得ます。各組の差と標準誤差はsuited_offsuit_differences.csvに保存しました。

## 5. 平均順位と分散を両方小さくするだけなら、AAが全手札を支配する

正確な169種類のモーメントでは、AAは平均順位も分散も単独の最小です。つまり両軸の小ささだけを好むパレート比較では、AAだけが残ります。

例えば a>0, b>0 の任意の固定重みで a*E[R]+b*Var(R) を最小化しても、169種類の中ではAAが最適になります。

そのため、この散布図を「平均は強いほどよい・分散は小さいほどよい」という単一の選択基準にすると、手札ごとの潜在性やプレイの違いを表す用途が失われます。高い順位分散を機械的に罰することと、ポーカー戦略上の優劣は別問題です。

## 6. 対戦結果の分散と、ボード別エクイティの分散は区別できる

相手1人との最終取り分をY（単独勝ち1、引き分け1/2、負け0）、エクイティをe=E[Y]、引き分け確率をtとすると、

E[Y^2] = P(win)+P(tie)/4 = e-t/4

Var(Y) = e(1-e)-t/4

です。これは既存の勝率・引き分け率から追加配布なしで計算できます。55の保存推定値を代入すると約0.235799832799です。ただしe,t自体が推定なので、この数値も推定です。

一方、Bを最終ボード、q(B)=E[Y|B,H]とすると、

Var(Y|H) = E[Var(Y|B,H)|H] + Var(q(B)|H)

したがって、0 <= Var(q(B)|H) <= e(1-e)-t/4 です。現在の勝敗集計からは、この上限までしか分からず、ボード別エクイティの分散そのものは復元できません。同じボード条件で相手の配布を平均する追加集計が必要です。

サンプル数nで現在のエクイティ標準誤差が sqrt(sample_Var(Y)/(n-1)) と一致することも確認しました。これは平均推定の誤差であり、順位分散ともボード別エクイティ分散とも別の量です。
