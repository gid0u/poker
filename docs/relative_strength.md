# 条件付きの相対勝率・エクイティ

順位と分散に加え、相手のハンドレンジに対して勝つ確率を計算します。
**同一の合法配布分布**から、予想順位、順位分散、標準偏差、単独勝率、
引分け率、敗率、エクイティを同時に求めます。

- 単独勝率: 自分だけが最強である確率。
- 引分け率: 自分が最強の1人であり、他にも同順位の勝者がいる確率。
- 敗率: 自分が最強でない確率。上の3つの合計は1。
- エクイティ: 単独勝ちは1、k人での引分けは1/k、負けは0として平均した取り分。

例: 全員がボードのロイヤルを使う3人戦では、単独勝率0、引分け率1、エクイティ1/3。
同じ予想順位でも、相手レンジによって勝率は変わります。相手の評価も**同じボード**で
行い、独立した別ボードとの順位比較にはしません。

## 通常入力

```python
with SevenCardRankDictionary() as table:
    result = table.relative_strength(
        hero="As Ah", board="Ks 8h 7d 3c 2s",
        opponent_ranges=["KK,QQ"], mode="exact",
    )
    print(result.mean_rank, result.variance_rank, result.equity)  # equity = 2/3
```

自分の2枚は実カード。ボードは0/3/4/5枚、未公開分を合法な残りカードから補います。
相手レンジは人数分のリスト（1〜8人）。`"random"` は全合法2枚コンボ、
`"AA,KK,AKs"` 等は既存レンジ表記です。APIではHandComboのリストや
`WeightedRange(((combo,weight),...))` も使えます。`dead_cards`で除外カードを指定。

相手レンジの重みの積を、全員のカード重複がないという条件で正規化します。
各相手の範囲を順番に再正規化して配ると偏りが出るため、その方法は使いません。
相手配布後、残りボードは合法なランアウトを等確率に扱います。
相手が持ち得るカードは自分の将来ボードから除かれるので、自分の予想順位・分散も
相手レンジなしの計算から変化し得ます。

`mode="exact"` は候補配布・ランアウトを全列挙（既定100万処理候補）。上限超過時は
部分結果を返さずエラー。`mode="sampling"` は各相手を独立に重み付き抽選してから
衝突した全配布を棄却し、ランアウトを抽選します。`samples=10000, seed=42`で再現可能。
サンプリングでは順位平均・分散・各確率は推定値です。分散は経験分布の母分散形式で表示。
エクイティの標準誤差は標本分散から算出し、95%CIは±1.96SEを[0,1]に切り詰めた
正規近似です。極端な確率や少数標本では精度が悪く、相手モデルの誤りは含みません。
exactのSE=0はサンプリング誤差がない意味で、条件の確実性を保証しません。

## 詳細ワイルドカード条件

```python
result = table.relative_wildcards(
    "As Ah Ks 8h 7d 3c X1", ["KK,QQ"]
)
```

X/O/P/Q/Rの既存規則を使い、最初の2枚が自分のホールカード、続く3/1/1枚が
フロップ/ターン/リバーです。ホールカードにも未知カードを指定可能。
`card_weights`、`dead_cards`対応。現状はexactのみで、一般条件は100万候補上限。
Hero側の成立状態重み×相手コンボ重みを合法性で**全体正規化**します。
各ボードで計算した勝率を無条件に等平均する方法は使いません。
順位と分散も、相手とのカード重複を除去した後の同じ分布に従います。

## GUI・CLI・保存

GUI「5 相対勝率」で、手札・ボード・相手1人につき1行のレンジを入力できます。
「詳細X条件」入力時は通常手札・ボード欄に代えて7枚パターンを使用し、exactを選択。
結果と条件をJSON保存できます。相手レンジは実コンボと正規化重み、seed、
サンプリング設定、方式を出力に記録します。既存SQLiteのEV履歴には自動挿入しません。

```powershell
.venv-studio/Scripts/python.exe scripts/evaluate_relative_strength.py --hero "As Ah" --board "Ks 8h 7d 3c 2s" --opponent "KK,QQ" --mode exact
```

この評価は指定した全員がショーダウンまで参加する仮定です。フォールド・ベット・
ポットオッズ・レーク・サイドポット・戦略的レンジ更新は扱いません。
エクイティをそのままベットやコールのEVと解釈しないでください。
