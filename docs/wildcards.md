# ワイルドカードの条件付き評価

7枚のうち未確定のカードやスートを指定し、条件を満たす**実カード集合すべて**の
強さを加重平均します。ジョーカーのように最強の完成形だけを選ぶ機能ではありません。

## 表記

|入力|意味|
|---|---|
|As / AS|確定したスペードA|
|X1 X2|異なる未知カード。確定カードや他の未知カードと重複不可|
|X2s|スペードに限定された未知カード|
|Qo Jo|QとJが同じ未知スートOを共有|
|Qo Kp|QのスートOとKのスートPは異なる|
|X1o|未知のランク、共有スート変数O|

大文字・小文字を区別しません。物理スートは S,C,H,D（スペード、クラブ、ハート、
ダイヤ）、スート変数は O,P,Q,R。変数は第5〜第8のスートではなく、未使用の物理
スートへの対応を表します。同じ変数は同じスート、異なる変数は異なるスートです。
すべての明示スートと除外カードのスートを予約してから変数を割り当てるため、
入力の順序を変えても条件の意味は変わりません。変数が候補スート数を超えればエラーです。

未知カードは最初に出現したものから X1,X2,... に正規化します。
例 `X9s X2` は `X1S X2` になります。裸の `X` / `Xs` / `Xo` も入力可能です。
同じ番号を2回書くと同一未知カードの重複指定になるため拒否します。
既知ランクにはスートを付けてください。`Q` 単独は曖昧なので受理しません。

`Qo` のOは「S/C/H/Dのいずれでもよい」という独立スロットではありません。
たとえば `As Ks Qo Jo 9s 8s 7s` ではOは C/H/D の3候補です。
`As Kc Qh Jd 9s 8s Qo` は4スートが予約済みなので成立しません。

## 分布・重み

重み未指定時は、条件を満たす**順序なしの実7枚集合**を等確率にします。
未知カードの入替えやスート割当方法の違いで同じ集合に到達しても重複計上しません。
たとえば固定5枚+無条件X1/X2は `C(47,2)=1081` 通りであり、47×46通りではありません。

`card_weights={"Ts":5}` のように実カードの重みを指定できます。未指定は1、
ハンド重みは含まれる7枚のカード重みの積です。さらにAPIの `hand_weight(cards)`
コールバックで集合全体の重みを掛けられます。重みは非負・有限、全体で正の質量が必要。
ゼロ重みは支持集合から除外し、`legal_hands` は正の重みを持つ実集合数です。

`mean_rank = Σ(weight × rank) / Σweight`。既存辞書と同じ1が最強の7462クラス基準です。
`mean_strength = 7463 - mean_rank` も返します。平均順位は実在の役・勝率・equityではなく、
序数スコアの期待値です。役タプルをそのまま算術平均しません。役カテゴリ確率と全順位確率も
返すので、`result.expectation(lambda rank: custom_utility(rank))` で別の尺度にも変換できます。

## API

```python
from poker_evaluator.seven_card_dictionary import SevenCardRankDictionary

with SevenCardRankDictionary() as table:
    result = table.evaluate_wildcards("As Ks Qs Js 2c 3d X1s", card_weights={"Ts":5})
    print(result.normalized, result.legal_hands, result.mean_rank)
    print(result.category_probabilities)
```

辞書なしでは `poker_evaluator.wildcards.evaluate_wildcards(pattern, ...)` が
既存評価器を使って同じ計算を行います（辞書使用より遅くなります）。
`WildcardPattern.parse(pattern).outcomes(...)` は正規化済み実カード集合と未正規化重みを
列挙します。`dead_cards=["Ts"]` で別の既知カードを除外できます。

CLI:

```powershell
.venv-studio/Scripts/python.exe scripts/evaluate_wildcards.py "As Ks Qs Js 2c 3d X1s"
```

GUIの「4 ワイルドカード」タブでも入力、除外カード、カード重みJSONを指定して計算し、
分布をJSON保存できます。既存の3人EV入力・SQLiteのスナップショット形式は変更しません。
ワイルドカードからの複数人レンジの自動構成やEV接続は別段階です。

## 正確さと計算量

サンプリングに黙って切り替えず、全列挙の正確な加重平均を返します。
一般条件の展開は既定で100万候補まで（重複除去前の完成割当数）。超過した場合は
部分的な平均を返さず `ExpansionLimitError` になります。API/CLIの
`max_candidates` を増やすことは可能ですが、ユニーク集合の重複排除にメモリを使います。
7枚すべてが無条件のXで重み・除外カードがない場合は、既存52C7辞書を直接集計し、
全133,784,560件を正確に扱います。既定の候補上限はこの直接集計には適用しません。

同じ7枚集合の中で位置に意味を持たせない仕様です。ボードとホールカード、別プレイヤー
のカードなど、役割を区別する配布分布としてそのまま利用しないでください。
